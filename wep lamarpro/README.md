# أعمال لمار للاتصالات وتقنية المعلومات

موقع رسمي لشركة **أعمال لمار للاتصالات وتقنية المعلومات** — يقدم حلولاً رقمية ذكية في إدارة الأساطيل والتتبع والذكاء الاصطناعي وإنترنت الأشياء لدعم التحول الرقمي في المملكة العربية السعودية.

---

## هيكل المشروع

```
wep lamarpro/
├── index.html          # نقطة الدخول الرئيسية (يُعيد التوجيه إلى lamar.html)
├── lamar.html          # الصفحة الرئيسية للموقع
├── lamar-style.css     # ستايلات الموقع الرئيسي
├── lamar-script.js     # السكريبت الرئيسي (منطق اللغة، الثيم، المحتوى)
├── admin.html          # لوحة إدارة المحتوى
├── admin-style.css     # ستايلات لوحة الإدارة
├── backgraound.mp4     # فيديو الخلفية في قسم الهيرو
├── media-data.json     # بيانات قسم الإعلام
├── contacts-data.json  # بيانات جهات الاتصال الواردة
├── careers-data.json   # بيانات طلبات التوظيف
├── img/                # الصور والشعارات
├── uploads/            # الملفات المرفوعة عبر لوحة الإدارة
└── api/                # ملفات PHP للخدمات الخلفية
    ├── auth.php        # مصادقة لوحة الإدارة
    ├── upload.php      # رفع الملفات
    ├── save-media.php  # حفظ بيانات الإعلام
    ├── save-contact.php# حفظ بيانات التواصل
    └── save-cv.php     # حفظ السير الذاتية
```

---

## المميزات

- **ثنائية اللغة** — واجهة كاملة بالعربية والإنجليزية مع دعم RTL/LTR
- **الوضع الليلي / النهاري** — تبديل الثيم بزر واحد
- **تصميم متجاوب** — يعمل على جميع أحجام الشاشات
- **لوحة إدارة** — إضافة وتعديل محتوى الإعلام وإدارة التواصل والسير الذاتية
- **خلفية فيديو** — قسم هيرو بفيديو متحرك في الخلفية
- **حماية بكلمة سر** — دخول لوحة الإدارة محمي

---

## التشغيل

يحتاج المشروع إلى خادم PHP لتشغيل ملفات `api/`.

### باستخدام PHP المدمج:
```bash
php -S localhost:8000
```
ثم افتح المتصفح على `http://localhost:8000`

### باستخدام XAMPP / WAMP / Laragon:
ضع مجلد المشروع داخل `htdocs` أو `www` وافتح الرابط المناسب.
