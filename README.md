# 🌐 Personal Portfolio | معرض الأعمال البرمجي

معرض أعمال تفاعلي يستعرض مجموعة من مشاريع تطوير الويب، تطبيقات الجوال، وأنظمة أتمتة العمليات الإدارية والدعم الفني.

## 🚀 المميزات الرئيسية (Features)
* **دعم ثنائي اللغة (i18n):** تبديل سلس بين اللغتين العربية والإنجليزية.
* **واجهة المظهر:** دعم كامل للوضع الداكن (Dark Mode) والوضع الفاتح (Light Mode).
* **تصنيف وتصفية المشاريع:** إمكانية فلترة المشاريع حسب المجال (منصات الويب، المسابقات، الأتمتة).
* **معاينة تفاعلية:** معاينة فورية للمشاريع عبر نوافذ منبثقة (Modals).
* **تصميم متجاوب:** متوافق تماماً مع جميع الشاشات والأجهزة المحمولة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **الواجهة الأمامية (Frontend):** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS
* **الخلفية وقواعد البيانات (Backend & DB):** PHP, SQL, MySQL
* **الأدوات (Tools):** Git, GitHub, i18n Dictionary

## 📂 المشاريع المعروضة (Featured Projects)
* **منصة مسار الأمل:** منصة توعوية وعلاجية تفاعلية للتعافي من الإدمان بخصوصية وسرية.
* **منصة شركة أعمال لمار (Lamar Work Co):** موقع شركة ولوحة تحكم متعددة الصفحات لتتبع الأسطول وتقنيات IoT.
* **منصة السياحة السعودية:** منصة معلوماتية واستكشافية لأبرز الوجهات السياحية في المملكة.
* **اختبارات SaudiSkills:** معرض استعراض وحدات اختبارات السرعة البرمجية للمسابقة الوطنية.
* **مولد الشهادات:** نظام أتمتة توليد الشهادات والخطابات الرسمية.
